## Tetris

![images](https://github.com/user-attachments/assets/b49087d1-8e10-41a1-95d0-d6d39b5e0ce2)

I made a Tetris game using python!
Tetris is a game that was made in 1984 by Alexey Pajitnov. Tetris is played in various countries and by millions of people.
Tetris game is a puzzle game where a collection of tetriminos fall down. When the tetrominos fill up a line, the line is deleted and the score goes up.

![tetris](https://github.com/user-attachments/assets/01bf148e-ab03-492b-b64f-141c7503555b)

The game starts with the tetrominos falling down from the top of the screen. The player can move the tetrominos or rotate them.

## Controls:
1. Right and left - moves the tetrominos
2. Up - rotates the tetrominos
3. Down - speeds up the falling speed of the tetrominos
4. Space bar - Drops the tetrominos
5. ESC - restart

When the tetrominos fill up the screen, the game is over and player needs to press ESC key to restart the game.
![game over](https://github.com/user-attachments/assets/2d01dcca-8c03-411b-a5b6-81e530404068)

## Conclusion:
This game was made by using pygame, which is a set of Python modules to make a game using Python.
By using Pygame library, the game handles graphics and controls. It was fun making this code and I would like to make more games using pygame in the future.
